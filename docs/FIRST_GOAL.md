# First Goal — 학생 관리 MVP 안정화

아래 내용을 Codex에서 실행한다.

```text
/goal

Studentory의 학생 관리 MVP를 검증 가능한 상태로 완성하라.

작업 범위:
- docs/ROADMAP.md의 M1 항목
- 학생 목록, 생성, 수정, 상세 조회, 정기 수업 일정
- 이 기능에 직접 연결된 FastAPI API, React UI, 타입과 테스트

작업 방식:
- AGENTS.md와 가장 가까운 하위 AGENTS.md를 따른다.
- $implement-feature-slice와 $verify-cross-stack을 사용한다.
- 한 번에 M1 항목 하나만 처리한다.
- 각 항목의 현재 기준선을 먼저 검증한다.
- 가장 큰 실패 원인 하나를 선택해 작은 변경으로 개선한다.
- 의미 있는 변경마다 관련 검증을 다시 실행한다.
- UI가 변경되면 $review-ui로 실제 화면을 확인한다.
- 결과와 다음 작업을 docs/LOOP_LOG.md에 기록한다.
- 기존의 관련 없는 작업 트리 변경을 수정하거나 되돌리지 않는다.

완료 조건:
- STU-001부터 STU-004까지 모든 수용 조건이 충족된다.
- 각 항목의 상태가 Done으로 갱신되고 검증 근거가 기록된다.
- backend에서 Ruff, Pyright, pytest가 통과한다.
- frontend에서 lint와 build가 통과한다.
- 학생 관리 핵심 흐름을 실제 브라우저에서 검증한다.
- 프론트엔드 타입과 API 동작이 백엔드 계약과 일치한다.
- 미확정 제품 규칙을 임의로 도입하지 않는다.

모든 완료 조건을 검증할 수 있을 때까지 중단하지 말고, 외부 결정이 반드시 필요한 경우에만 정확한 질문과 영향 범위를 기록하라.
```
